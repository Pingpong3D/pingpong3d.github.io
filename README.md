# Pingpong3D

一路机位，还原整场乒乓球比赛的三维。项目主页：https://pingpong3d.github.io/

Whole table tennis matches in 3D from a single camera. Project page: https://pingpong3d.github.io/en/

演示视频 / Demo video: https://www.youtube.com/watch?v=5e6fQDLpLy0

这个仓库只放项目主页（静态网页和演示片段），不含系统代码。片段里的比赛画面来自公开转播，版权归原转播方所有，这里只用于技术演示。

This repository only hosts the project page (a static site and demo clips), not the system's code. Match footage in the clips comes from public broadcasts; all rights belong to the original broadcasters, and it is used here only for technical demonstration.
